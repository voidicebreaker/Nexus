DESKTOP AI / WINDOWS HOST SETUP

Leave the compute at home.
Take the conversation with you.

Connect LM Studio to your website. Your friends only need a browser, your chat link, and a private access key.

Download Windows launcher ↓64-bit Windows · no programming needed
01

Download and extract

Download the ZIP above. In File Explorer, right-click it and choose Extract All. Open the extracted folder. Keep all its files together.

The first launch downloads Node.js and Cloudflare Tunnel from their official releases and verifies their SHA256 checksums. It installs them for your Windows account, without administrator access.

02

Start LM Studio's local server

Open LM Studio and load a chat model that works on your desktop. Open Developer in the left sidebar, then start the local server.

Use port 1234. Leave Serve on Local Network and Enable CORS off: the launcher connects locally and handles remote access.

If Require Authentication is on, create or copy an LM Studio API token in Manage Tokens. The launcher will ask for it privately. This token stays on the desktop; do not give it to friends.

Leave per-request MCPs and calling servers from mcp.json off for this text-chat setup.

03

Double-click Start-LM-Share

In the extracted folder, double-click Start-LM-Share.cmd. Give the first launch a few minutes to download its tools. It checks LM Studio, starts the connection, and opens the chat page in your browser.

The sharing window displays a private access key and a chat link. Copy the key into the chat page and click Connect to desktop. The desktop address is already filled in when you use that link.

Choose your model, then send a test message.

04

Give friends the link and key

Share the chat link printed in the window and the private access key through a private channel. Friends open the link, paste the key, and connect. They do not install anything.

Keep the desktop awake and leave LM Studio and the sharing window open while you are away. Closing the window or pressing Ctrl+C stops sharing. Models run one request at a time; up to four more requests can wait.

One thing to remember: the temporary address changes when you restart the sharing launcher. Use the new chat link each time. The access key stays the same until you run Reset-Access-Key.cmd. No domain or router changes are needed.

If something doesn't connect

“LM Studio is not responding”

Start the server in LM Studio's Developer view and check that its port is 1234. Load a chat model, then restart the launcher. If you deliberately use another port, it can be set with the MOM_LM_URL environment variable; the standard setup needs no changes.

“Access key is missing or incorrect”

Use the private access key printed in the Windows sharing window, not the homepage password or the LM Studio API token. Copy the whole key without spaces. If it was reset, everyone needs the new key.

“Cannot reach the desktop” or tunnel unavailable

The desktop must be online and awake. Check that the sharing window is still open, and use its latest chat link. Temporary tunnels can briefly take time to become reachable; try Connect again after a few seconds. If the launcher reports a tunnel connection error, check your internet connection and whether your network permits outbound port 7844.

The model appears but cannot answer

Select a text chat model, rather than an embedding model. Load it in LM Studio and check it works there first. A context-window error usually means you should start a New chat or use a shorter prompt. Each reply is limited to 2,048 tokens and ten minutes to keep sharing manageable.

I want to revoke access

Close the sharing window to stop all remote access immediately. To change the private key, close that window and double-click Reset-Access-Key.cmd. Give the new key only to the people you want to retain access.

What is private, and what gets saved?

The website never saves the private key or conversation to browser storage. It remembers only the desktop address. Reloading clears your chat. The desktop relay keeps requests and replies temporarily in memory and does not write chat logs. LM Studio may log requests, and the host can see them. Traffic passes through Cloudflare, which terminates HTTPS, so this is not end-to-end encryption between browser and desktop.

The private key is saved in your Windows account under %LOCALAPPDATA%\MindOverMatterLLM. Everyone with the key can use the shared chat service. Only model listing and text chat are exposed; this does not grant remote desktop, shell, file access, or unrestricted access to LM Studio's model-management API.

Can I use a permanent address or an API client?

This first setup uses a free temporary Cloudflare Quick Tunnel, with no account or DNS changes and no uptime guarantee. A named tunnel can later give it a permanent address such as llm.mindovermatter.space; the chat page already accepts that hostname. The desktop relay uses a small authenticated job API for this chat page. It is not a direct OpenAI-compatible endpoint for coding tools.
