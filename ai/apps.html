Download updated Windows launcher ↓First-time host setup
Already downloaded the old launcher? Close its sharing window, download and extract this updated ZIP, then run Start-LM-Share.cmd from the new folder. Your existing private access key is reused from your Windows account. The old launcher does not have these API routes.
01

Find the three values

Start LM Studio and the updated launcher on your desktop. Its window prints:

  • PRIVATE ACCESS KEY — paste this in each app's API key field.
  • API BASE URL — use this in SillyTavern and Open WebUI. It ends in /v1.
  • JANITORAI PROXY URL — use this in JanitorAI. It ends in /v1/chat/completions.

The launcher also lists the available model identifiers. Use the exact identifier of your loaded text-chat model. Do not enter your website's chat-page address as an API URL.

The sharing key is different from an LM Studio API token and a Cloudflare tunnel token. Those two host credentials stay on the desktop.

For the temporary tunnel, turn streaming OFF in the app. This mode returns each completed reply in one response. API requests have a 90-second total limit, including queue time. Preload your model and try a short reply first. The website's own chat still shows incremental updates through polling. For streaming or a permanent address, see below.
02

SillyTavern

Open API Connections. Set API to Chat Completion, then choose Custom (OpenAI-compatible) as the source.

Custom Endpoint: paste the launcher's API BASE URL.
Custom API key: paste the PRIVATE ACCESS KEY.
Model: select your LM Studio model from the list, or enter its exact identifier.

Do not add /chat/completions to SillyTavern's endpoint. Turn streaming off for a temporary tunnel, then use Test Message.

03

JanitorAI

Inside a character chat, open the menu and API Settings. Choose Proxy and Add Configuration, if available in your account.

Configuration name: My desktop.
Proxy URL: paste the full JANITORAI PROXY URL.
API key: paste the PRIVATE ACCESS KEY.
Model: enter the exact LM Studio model identifier.

Here the URL does include /v1/chat/completions. Save and activate the configuration, refresh the chat, and send a short test message. Turn streaming off for a temporary tunnel. If your JanitorAI interface does not offer that switch, use the permanent-tunnel mode below.

04

Open WebUI

Open Settings → Admin → Connections. Under Manage OpenAI API Connections, add a connection.

URL: paste the API BASE URL.
API key: paste the PRIVATE ACCESS KEY.

Verify the connection, save it, and select your model. Open Chat Controls → Advanced Params and set Stream Chat Response to Off for a temporary tunnel. If your account-wide setting overrides it, check Settings → General → Advanced Parameters too. Keep tools, attachments, web search, and function calling off for this text-chat connection. Automatic title and follow-up requests also use the shared GPU queue.

Use the public tunnel address even if Open WebUI runs in Docker on your laptop; localhost there refers to the laptop or container, not your desktop at home.

Optional: permanent address and streaming

Use this when you want a stable API address, streamed replies, or an app that cannot disable streaming.

This requires a Cloudflare account and the domain's DNS to be managed by Cloudflare. The temporary mode above needs neither. If your DNS is elsewhere, test temporary mode first; do not change nameservers just to follow these instructions.
A

Create a named Cloudflare Tunnel

In your Cloudflare dashboard, create a Cloudflare Tunnel using the cloudflared connector. Add a published application route with hostname llm.mindovermatter.space, service type HTTP, and service address 127.0.0.1:8787. Leave the path blank so both the website chat and the API can reach the relay.

The destination is the relay on port 8787, not LM Studio's port 1234. The relay enforces the private key. A browser-only Cloudflare Access login would prevent these API clients from connecting unless separately configured for them.

B

Run the permanent-tunnel launcher

Close any running sharing window. Double-click Start-Permanent-Tunnel.cmd in the updated ZIP. When asked for the public address, press Enter to use https://llm.mindovermatter.space.

Cloudflare's connector setup displays a command containing a tunnel token. Paste only that token into the launcher's hidden prompt. You do not need to install its Windows service. The token is not saved by this launcher and is never given to friends or entered in chat apps.

After the tunnel connects, use the printed addresses and private sharing key in your apps. Streaming is enabled in this mode; the address survives restarts. Use streaming for slow or queued requests: non-streaming requests can still hit a client's or proxy's timeout before the relay's ten-minute deadline. Cloudflare must have the hostname correctly routed before it can be reached.

Supported scope

Text chat and model discovery: GET /v1/models and POST /v1/chat/completions. System prompts, character names, and common sampling controls are supported. Replies are capped at 2,048 tokens; one generation runs at a time, with four waiting slots shared with the website.

Tools, images, audio, embeddings, Responses API, and model-management operations are not exposed. The relay has automated protocol tests; live end-to-end testing in your three apps still requires your desktop and accounts.
